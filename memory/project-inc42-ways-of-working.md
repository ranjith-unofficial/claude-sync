- Utkarsh also created and shared the newer project discussed separately (name garbled in transcript — confirm which).
- **Open:** Ranjith to explore all of these and propose how to use them together, specifically so unification work has a home and so everything reaching Satya/the tech team sits in one place.

**Daily cadence (Utkarsh's instruction).**
- Ranjith + Ashish run a **15-min daily standup** with Satya, Ritvik and team. Already happening; format is yesterday's work → today's plan → blockers.
- **New:** after standup, **summarise priorities in the channel** — what's on everyone's plate. Utkarsh wants the same visibility and will review himself.
- **New:** everyone posts **daily updates in the "Techwalla" channel** — completed yesterday, working on today. Ranjith posts his own too, including what he's working on with Utkarsh.
