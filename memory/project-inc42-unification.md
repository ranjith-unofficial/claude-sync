**How to apply:** the plan recommends (in order): 1) single INC42 ID + one shared Watchlist object across all three surfaces (blocking dependency for everything else), 2) auto-link companies in articles + add Follow/"Covered in" to the existing free company pages, 3) feed DataLabs events (funding/filings/exec moves) into [[project-inc42-social-intelligence]] (Pulse) as the alert engine, 4) put a DataLabs upgrade entry point inside the app's existing Explore/Watchlist IA rather than a separate tab, 5) retire the Inc42 Plus listing.
