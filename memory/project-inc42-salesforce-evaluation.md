**2026-08-24 — "Unified Data and Marketing Automation" scoping call with Salesforce reps.** Not a decision meeting — Salesforce scoped how Inc42 could unify user data, marketing, and Slack agents; Ranjith steered toward data unification over a feature/business pitch.

**Context Ranjith gave them:** Inc42 gets ~5–6 lakh unique visitors/month, historically IP-events-focused, now shifting to funnel/engagement/retention. He owns product across website, app, Data Labs (not IP), currently focused on app acquisition/engagement. No unified view of the user journey across properties — pulling DB dumps manually doesn't scale. Inc42 is already building an in-house data warehouse ([[project-inc42-data-warehouse]]) and running ~100 Slack users with some in-house agents deployed ([[project-inc42-agent-platform]]).

**What Salesforce pitched:**
- **Data 360** (formerly Data Cloud) as the unifying data layer + **Marketing Cloud** for activation, sold on hyper-personalization (experiential, not just clicks) across acquisition/engagement/retention/analytics.
- **Slack Enterprise** bundled with Slackbot (Claude), unlimited AI, MCP for cross-agent context, and Slack code — positioned against the in-house Slack agent work already underway.

**Decision: two follow-up sessions, not one.**
1. **Marketing Cloud + Slack** — first, 60 min, Thursday second half of day. Ranjith to pull in Inc42's data-lead (building the warehouse); Salesforce to bring a marketing specialist + a Slack specialist. Salesforce to share collaterals/an acquisition-to-retention doc beforehand.
2. **Subscriber lifecycle** — second, no date set yet.

Framed as capability-sharing + two-way brainstorming, not a product pitch.

**How to apply:** evaluate this against the in-house build already in progress ([[project-inc42-data-warehouse]], [[reference-inc42-vendor-stack]]) — don't treat Data 360/Marketing Cloud as a foregone adoption. No budget, timeline, or vendor decision has been made; this was scoping only. Check [[project-inc42-agent-platform]] before any Slack-Enterprise-vs-in-house-agents conversation, since that's an existing, staffed initiative this pitch would displace.
