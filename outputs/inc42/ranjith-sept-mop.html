The AI agent system

The FY27 plan gives me Internal AI & Agent Platform — platform, with Prapti on pilots. The ratified September MOP has one AI row and it names only Prapti, so the platform half is committed in the horizon plan and served by no row. This is what it means concretely.

What shipsMulti-role hiring agent
The first real agent on the platform, not another pilot. One workflow, per-role sheet config, live for at least two roles. Two-step CTC rule implemented as agreed with Utkarsh. The broken experience computation fixed.
What makes it a platformThe contract
Written down: how a new agent gets specced, deployed, monitored and costed. Without this, every agent is a one-off build and the fifth one costs as much as the first.
What makes it measurableCost instrumentation
Per-agent cost captured from day one, so the A11 cost-per-QIA baseline is readable in October — the first month QIA itself is properly measurable.
What blocks itTwo gates
DPDP consent scope for candidate data is unresolved — this decides whether the hiring agent can process applicant data at all. And the Keka API is a paid add-on, confirmed. Both need answers in week 1.
