Guardrails — grouped by track, not repeated 8×

Transient

  • Never cut access for a funds-only issue — the mandate is fine.
  • Never ask this customer to re-authorize.
  • If a manual payment and an auto-retry both land, auto-refund the duplicate.

Needs re-auth

  • Never retry a dead token — re-auth is the only path back.
  • Never grant access on an unconfirmed mandate — the ₹92,665 bug.
  • Never restart the clock if a cancellation arrives mid-track.

Cancellation

  • Never create a renewal order against an already-cancelled mandate.
  • Never cut access before the paid-through date ends.

Terminal

  • Never message again once terminal.
  • Never give a resubscribe a second free trial.
